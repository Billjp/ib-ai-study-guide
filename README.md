# IB生に伝えるAI術

IB DP生向け、日本語のAI活用ガイド。

- [GitHub Pagesで読む](https://billjp.github.io/ib-ai-study-guide/)
- [Sitesで読む](https://ib-ai-study-guide.windowsbeliever.chatgpt.site)

## 内容

AIの種類とおすすめ、質問の作り方、ThinkingとFast、NotebookLM / Open Notebook、MCP、Cursor / Antigravity、Obsidian、EE・IA・TOKでのAI利用と出典の扱いを8章で紹介します。検索、ツールの絞り込み、コピーできるプロンプト、科目別テンプレート作成があります。

## Cookie・保存設定

初期状態では読了記録を保存しません。設定を覚えるCookieは180日間、読了記録は許可後だけlocalStorageに保存します。設定を取り消すと保存済み読了データを削除します。Cookie・保存設定はページ下部からいつでも変更できます。アクセス解析・広告用Cookieは組み込んでいません。ホスティング提供元の通信ログ等の扱いは提供元の方針に従います。

## 編集とローカル確認

ビルド不要のHTML / CSS / JavaScriptです。

- 本文、ツール、プロンプト、出典：content.js
- 画面と機能：app.js
- デザイン：style.css
- Cookie設定：privacy.js / privacy.css
- メタデータ：index.html

このフォルダで `python -m http.server 8000` などのHTTPサーバーを起動してください。GitHub Pagesはmainブランチのルートから公開します。
